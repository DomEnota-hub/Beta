# Документальный аудит приёмки — Beta50

Дата повторной проверки: 23.09.2026.

## Решение по структуре

| Категория | Что входит | Как реализовано |
|---|---|---|
| Обязательная приёмка | Только укрупнённые действия, прямо относимые руководством к приёмке/ТО-1 локомотивной бригадой | Отдельный короткий маршрут: 15 пунктов для ВЛ80С и 18 для 2ЭС5К/3ЭС5К |
| Полный осмотр | Детальные карточки оборудования, проверки по зонам и дополнительные диагностические признаки | Отдельные маршруты с выбором начала из кабины или снаружи; не объявляются нормативной ежедневной последовательностью |
| По условиям | Работы для конкретного исполнения, после ремонта/отстоя, при погодных и местных условиях | Универсальный маршрут не создаётся. Условие остаётся в карточке полного осмотра, а отсутствующий узел можно отметить «Не применяется» |

Обязательные пункты включаются в начало полного осмотра с теми же идентификаторами. Поэтому отметка физического объекта сохраняется между режимами и повторно ставить её в одной сессии не требуется.

## ВЛ80С

Сверены разделы руководства по эксплуатации ВЛ80С «Техническое обслуживание ТО-1 электровоза локомотивными бригадами» и «Приёмка электровоза в депо», а также разделы 2.1, 2.2 и приложение 2 Инструкции ЦТ-685 от 27.09.1999.

Результат:

- обязательный маршрут содержит 15 укрупнённых пунктов;
- 66 детальных карточек из технического набора остаются только в полном осмотре;
- приложение 2 ЦТ-685 содержит примерный перечень, поэтому приложение не выдаёт его за неизменяемый универсальный объём;
- фактический объём уточняется утверждённым перечнем депо и действующими местными инструкциями;
- ссылка старого руководства на ЦТ/3549 не показывается как действующая инструкция; для тормозов используется нейтральная отсылка к действующему документу.

## 2ЭС5К / 3ЭС5К «Ермак»

Сверено руководство по эксплуатации ИДМБ.661142.009РЭ7 (3ТС.001.012РЭ7), книга 7 «Использование по назначению», раздел 3.10 «Техническое обслуживание ТО-1».

Результат:

- обязательный маршрут содержит 18 укрупнённых пунктов раздела 3.10;
- осмотр механической части и тяговых двигателей сопровождается границей безопасности: электровоз заторможен, токоприёмник опущен;
- 111 карточек оборудования не включены в обязательный маршрут автоматически и используются только для полного осмотра;
- карточки полного осмотра прямо предупреждают, что сформированный по расположению маршрут не является подтверждённой нормативной последовательностью ежедневной приёмки;
- отсутствующий на конкретном исполнении узел отмечается «Не применяется» без переноса характеристик между 2ЭС5К и 3ЭС5К;
- ссылка руководства на ЦТ-533 не показывается как актуальная инструкция; для тормозов используется отсылка к действующему документу.

## Контракты реализации

- Количество обязательных пунктов и их статус проверяются при загрузке данных.
- Дубли идентификаторов обязательной части запрещены.
- Полный осмотр строится как `обязательные ID + расширенные ID` с удалением повторов.
- Внутренние значения расположения проходят через единый словарь отображаемых русских названий; тест охватывает все 78 значений из набора Ермака.
- Значения `pneumatic_block`, `reservoir_group` и `compressor_discharge_line` отображаются как «пневматический блок», «группа резервуаров» и «нагнетательная линия компрессора».

## Ограничение

Приложение не заменяет руководство конкретного локомотива, действующий обязательный перечень депо, местные инструкции и документы работодателя. При расхождении приоритет имеет документ, действующий на месте эксплуатации.
