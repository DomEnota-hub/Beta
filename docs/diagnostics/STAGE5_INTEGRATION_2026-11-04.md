## Исправление источниковой ошибки

В исходном локальном пакете материал А. А. Потанина 2018 года ошибочно
использовался для обоснования отдельных **GV/ГВ** ветвей.
Проверенная часть публикации описывает неисправности цепи ЭКГ.
Точное наличие в ней ГВ-раздела не подтверждено. Поскольку гадать
в этом проекте запрещено, исходная запись `gv2018` не удалена, но
получила `SOURCE_SECTION_MISMATCH_UNRESOLVED` и
`usableForScenario=false`.

Соответствующие два **информационных фокуса** перепривязаны:
различение включения и немедленного отключения к публикации 2004 года
(её раздел «Цепи управления ГВ»), а вопрос защитной индикации — к
публикации 2011 года (раздел «Цепи главного выключателя»).
Текущая применимость этих исторических рекомендаций НЕ подтверждена.

Инструкция депо Батайск для ЭКГ — исторический локальный источник;
полный текст при текущем просмотре не получен, точные пункты и
право машиниста на действие не подтверждены. Любые старые советы
про перемычки, ручное воздействие и обход защиты
не импортированы как процедура.

## Запреты, неопределённости и приёмка

`publicationStatus=CANDIDATE`, `runtimeImport=false`,
`executable=false`, `actionAuthorityGranted=false` для обоих графов.
Расширения скрыты по умолчанию; ознакомление с предупреждением до
конца требуется, но **текущий Android UI не подключён к этим данным**.

Канонический корпус 340 сценариев/3902 узла, исходные версии
`NOT_AUTHORED` и пятирёберный первичный граф остаются без замены.
Исходный runtime-граф сравнен по канонической идентичности и числу
узлов из сохранённого реестра; **полную последовательность донорских
узлов через GitHub API выгрузить не удалось**. Поэтому
`actualRuntimeGraphCompared=false`.

QA: `qa/validate_stage5_research.py` и
`qa/test_stage5_research.py`, совместно с уже действующими
Stage1–5 baseline checks, Kotlin/runtime policy, Android lint, debug
assembly и проверкой APK. Публикация возможна только после отдельного
полного источникового, нормативного, профильного, ролевого и safety review.

## Примечание о воспроизводимости CI, 04.11.2026

Первый CI на коммите `378eaf2e749a21b675df82b3f639ebab1aeb9c07`
успешно выполнил Stage 5 QA, но упал в предсуществующей проверке
`qa/replay_family_generators.py`: **12 gzip-артефактов ЧМЭ3**
после переупаковки на `ubuntu-latest` имеют другие SHA.
Сопоставление Actions logs установило смену окружения:
21.10 — Ubuntu 24.04.5, 04.11 — Ubuntu 26.04.1.
Генератор использует `gzip.compress(payload, compresslevel=9, mtime=0)`.
При смене Python/zlib байтовое представление gzip может измениться
даже без изменения распакованного содержимого. Полная бинарная
декомпозиция различий ещё не проводилась, поэтому этот диагноз
остаётся **объяснением окружения**, не доказательством идентичности
всех распакованных байтов.

В CI зафиксирован runner `ubuntu-24.04`, идентичный ОС ранее
успешной проверки, **без** перезаписи donor golden hashes,
изменения generator scripts или исходных сценариев.
Результат повторного CI фиксируется отдельно по факту.
