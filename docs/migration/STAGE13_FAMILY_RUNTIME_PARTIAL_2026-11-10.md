Дата: 10.11.2026. Ветка `audit/information-block-gaps-20261014`. Донор `Test-` @ `3176d6ee228f0ed4b78371f45209e10c1c724eff` только для чтения.

## Реализовано в Android, а не только в документации

- `MainActivity`: при выборе любой из семи моделей семейств Ермак (2ЭС5К/3ЭС5К), ЧМЭ3 (ЧМЭ3/Т/Э) и ТЭМ2 (ТЭМ2/У) переходы «Атлас», «Приёмка», «Диагностика» ведут в отдельный `FamilyContentScreen`, а не в ВЛ80С.
- Исполнение выбирается **внутри раздела**. Не подставляется автоматически из рабочей модели. Для 2ЭС5К/3ЭС5К МСУД-Н и МСУД-015 разведены; для ЧМЭ3Т разведены диапазоны до/от №6245. Неизвестное исполнение закрывает просмотр.
- `FamilyContentCatalog` читает только структурные `*.pack.json` из семейных каталогов, пропускает `migration`, `research`, диагностические `recommended` и расширенные архивы. Непарсируемые пакеты не публикуются.
- `FamilyPublicationGate` проверяет модель-владельца, **точное исполнение**, ACTIVE, CURRENT, подтверждённое происхождение, STANDARD, INFORMATION_ONLY, наличие всех подтверждённых sourceRefs. Источник должен сам иметь ACTIVE/CURRENT и быть применим **к тому же исполнению**. Семейные карточки без явного исполнения закрыты. Диагностические сценарии не выводятся как информационные карточки, отдельный граф и safety gate пока не подключены.
- В интерфейсе готов путь к карточке и её информационным блокам только после успешного допуска; прямые ссылки из неё временно закрыты до отдельной авторизации.
- В текущих проверенных образцах исходных пакетов Ермак, ЧМЭ3 и ТЭМ2 записи имеют `CANDIDATE/UNKNOWN`, поэтому **реальных опубликованных карточек новых семейств в этом запуске нет**. Это сознательный fail-closed, а не завершённая интеграция.
