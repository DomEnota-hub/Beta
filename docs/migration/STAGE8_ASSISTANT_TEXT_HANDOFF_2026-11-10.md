Дата: 10.11.2026. Ветка: `audit/information-block-gaps-20261014`.
Донор `Test-` @ `3176d6ee228f0ed4b78371f45209e10c1c724eff` только для чтения.

## Реализовано в Kotlin Beta
- `assistant-core/AssistantTextEngine.kt`: раздельные parser, индексируемый поиск, engine, conversation. Не LLM; не генерирует ремонтных инструкций.
- Разрешение рабочего локомотива и явно названной серии без переключения рабочего контекста. Неоднозначный «Ермак» требует уточнения 2ЭС5К/3ЭС5К, конфликт двух серий тоже закрывается уточнением.
- Поиск читает только `ContentRegistry`, прошедший валидацию. Допускает только `ACTIVE`, `INFORMATION_ONLY`, `STANDARD`, модельную применимость и опубликованные модельные runtime; исключает `CANDIDATE`, действия и неподтверждённые исполнения. Диагностические/безопасностные карточки требуют подтверждённого активного официального/заводского источника.
- Ссылки на источники являются атрибуцией, не автоматическим подтверждением. Автопереход возможен только к уверенно найденной информационной карточке с проверенным источником.
- `content-runtime/ContentRegistry.kt`: неизменяемый snapshot записей для поиска.
- `app-shell/MainActivity.kt`: engine создаётся из валидированного runtime ВЛ80С; пользовательский Compose UI поиска отдельно в этапе 9.
- `AssistantTextEngineTest.kt`: 12 unit-тестов контекста, исключений, неоднозначности, статуса публикации, ссылок и исполнения.

## Ограничения и следующий этап
- Это проверенный текстовый backend, **не готовый пользовательский экран**; UI ассистента будет этапом 9.
- Словоформы, опечатки, жаргон, полная донорская лексическая паритетность и матрица `запрос → намерение → карточка → источник` остаются отдельным этапом 10. Полный перенос всех донорских семантических эвристик пока не подтверждён.
- Общие материалы с `CANDIDATE` и неподтверждёнными источниками не открывать в runtime.
- Варианты исполнения без явного подтверждения закрыты; данные 2ЭС5К/3ЭС5К/ЧМЭ3/ТЭМ2 не подмешивать к ВЛ80С.
- Следующее действие: этап 9, Compose UI текстового ассистента с поиском, карточками, уточнением серии, сохранением запроса и безопасной навигацией по `ContentRegistry`.
